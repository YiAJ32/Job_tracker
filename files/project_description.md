# Descripción del Proyecto

Este proyecto consiste en una aplicación para rastrear solicitudes de trabajo (job tracker).

## Funcionalidades principales

### 1. Rastreo de solicitudes de trabajo

La aplicación permite llevar el registro de las solicitudes de trabajo realizadas, almacenando la siguiente información para cada una:

- Nombre de la empresa
- Puesto
- Estado (de la solicitud)
- CV utilizado

### 2. Revisión de CV tipo ATS

Adicionalmente, la aplicación cuenta con un apartado para revisar el CV contra la descripción del trabajo, funcionando de manera similar a un ATS (Applicant Tracking System). Este apartado permite obtener un nivel de matching (coincidencia) entre el CV y lo que se busca para el puesto según la descripción del trabajo.
